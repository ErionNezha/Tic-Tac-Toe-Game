# X dhe O · Mund AI-në ❌⭕

Loja klasike X dhe O kundër inteligjencës artificiale — a mund ta mundësh në nivelin e vështirë?

**Live:** https://erionnezha.github.io/Tic-Tac-Toe-Game/

## Veçori

- 🤖 AI me 3 nivele vështirësie:
  - 😌 **I lehtë** — lëvizje rastësore
  - 🙂 **I mesëm** — 50% lëvizja më e mirë + 50% rastësore
  - 🤖 **I vështirë** — algoritmi minimax i plotë, i pamposhtur
- ❌⭕ Zgjidh shenjën tënde (X ose O) — ti luan gjithmonë i pari
- ✨ Vija fituese e animuar me shkëlqim gold
- 🏆 Scoreboard (Ti / Barazime / AI) i ruajtur në `localStorage`
- 📱 Responsive, UI plotësisht në shqip

## Si luhet

Zgjidh nivelin dhe shenjën, kliko një qelizë dhe AI përgjigjet automatikisht.
